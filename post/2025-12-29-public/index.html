介绍怎么在这个网站发布内容

 发表于 December 28, 2025  |  firlight

在本网站上发布内容，仅需撰写 markdown 文件即可，不需要网站或编程知识。

第一步，指定文章的样式

在你创建的 markdown 文件的开头，添加以下内容：

+++
title = '你的标题'
subtitle = '你的副标题'
author = '你的名字'
date = '2025-12-28T22:36:03+08:00'
type = 'post'
image= ''
tags = ["模版", "说明"]
something = ''
+++

请在以+为首尾的内容段中编辑这篇博客的样式，样式格式为：XX = XX。 你可以自定义样式内容，包括样式名称和样式内容，如果我的代码可以支持的话，如果暂时不支持，请让你的格式保持：XX = ‘’。

以下为样式说明：

  • title：标题
  • subtitle：副标题
  • author ： 本文作者
  • date ：本文发布的时间（北京时间）
  • type ： 界面的渲染模版
  • image： 文章封面
  • tags ： 文章标签
  • something ：自定义示例

第二步，编写你的文章内容

很简单，只要是 markdown 的内容即可，如果你觉得 md 文件的默认渲染方式太丑，这里也支持自定义的渲染方式，如果我的代码可以支持的话。

请保证你的内容在文章的样式后面，也就是在+的内容段后面开启你的全部内容。

第三步，内容发布

为了方便管理，请将文件名改为"日期-标题"，日期样式为 year-month-day，示例：2025-12-28。

文件中需要用到的资源，如图片、资源文件等，请放到根目录 static 文件夹下。

最后一步，等待服务器进行渲染

你可以自己进行渲染或者等待我进行渲染。

网站渲染前的内容，会放在 github 管理仓库中，你可以直接 点击此跳转

如果你想自助渲染，请先联系我取得仓库权限，然后将仓库内容 clone 到本地。

在本地文件中，使用系统命令行

hugo server -D

请保证当前目录下存在 hugo.exe，然后等待渲染，你可以在本地预览效果，一般为 http://localhost:1313，当然你可以直接查看系统命令窗中的信息。

渲染结束之后，将得到的 public 文件夹 push 到网站的仓库即可。

当然，为了实现你的自助渲染，你也必须将渲染前的整个文件，push 到管理仓库中点击此跳转
