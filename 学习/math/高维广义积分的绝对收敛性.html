广义二重积分的绝对收敛性 1

定理：在无界区域 P 上, ∫ P f(x) d x 积分存在 ⇔ ∫ P | f(x) | d x 积分存在.
证明：

⇐ f + = | f | + f 2 , f − = | f | − f 2 ,f= f + − f − 而 f + ≤ | f | ,  f − ≤ | f| 故显然成立。

⇒ 反证 :假设取一区域序列 { P n } ，使越往后，逐渐覆盖且趋近于 (P) ，
而我们恰有 lim n → ∞ ∬ P n | f | d x=+∞.
不失一般性，我们可以设，对每一值 n ，不等式 ∬ P n + 1 | f | d x>3 ∬ P n | f | d x+2n 成立（这是办得到的，只要在必要时割裂序列 { P n } ，即从它里面去掉一个子序列再重新编号即可）。
记 P n ′ 表示 P n + 1 与 P n 的差，则有 ∬ P n ′ | f | d x>2 ∬ P n | f | d x+2n. 但 |f(x) | = f + + f − ，故 ∬ P n ′ | f | d x= ∬ P n ′ f + d x+ ∬ P n ′ f − d x. 则对 f + 与 f − ，不妨设 f + 满足 ∬ P n ′ f + d x> ∬ P n | f | d x+n. 左边的达布下和满足： sup∑ m n ( i ) μ( p n ( i ) )> ∬ P n ′ f + d x> ∬ P n | f | d x+n, 即 ∑ m i μ( p n ( i ) )+ϵ> ∬ P n ′ f + d x> ∬ P n | f | d x+n. 令 ϵ→0 ,则有 ∑ m n ( i ) μ( p n ( i ) )> ∬ P n | f | d x+n. 在这一和中，可只留下与 m n ( i ) >0 相对应的项， 以 P ― n 表示对应于这 p i ( n ) 对应的集合。
有 ∬ P ― n f d x= ∬ P ― n f + d x> ∬ P n | f | d x+n. 而 ∬ P n f d x>− ∬ P n | f | d x 则 ∬ P ― n ∪ P n f + d x>n. 最后，使 P ― n ∪ P n 中孤立之部分用狭窄的长连通起来，其长方形之面积任意小，联结之后的区域记作 P n ″ ， 并且 ∬ P n ″ f d x与 ∬ P n ′ ∖ P n f d x十分接近
故 ∬ P n ″ f d x>n, 从而 ∬ P f d x 不存在,产生矛盾。

:bulb: 提示1： P ― n 是 P n ′ 的一部分，所以 P ― n ∪ P n 可以相加。
:bulb: 提示2： 可以证明 ∬ P n ″ f d x 中,令 n→∞ ,有 ∬ P n ″ f d x= ∬ P f d x
